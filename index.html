Prototipo UI: "Edukacion Mortal"

Este proyecto consiste en el diseño conceptual, creación de assets y maquetado de interfaz para un videojuego de peleas 2D en estilo pixel art, protagonizado por personajes basados en estudiantes de preparatorias de Sonora, como el CBTIS.

El objetivo principal fue establecer una dirección de arte clara y diseñar los flujos de interacción del usuario, abarcando desde las pantallas de selección y menús de inicio hasta los escenarios de combate que reflejaran la identidad local.

Para abordar esto, se planificó una arquitectura de información sencilla orientada a consolas y PC. Se conceptualizó la disposición de los botones interactivos (Jugar / Menú) y se estructuró la jerarquía visual para que el logotipo y los luchadores destacaran sobre los fondos detallados de las escuelas.

La construcción gráfica y el ensamblaje de los componentes visuales se llevaron a cabo utilizando Canva. Mediante esta herramienta, se organizaron las capas de los sprites, la tipografía retro y los elementos del HUD para simular la vista real del motor de juego.

El resultado es un mockup inmersivo y altamente detallado que visualiza con éxito la experiencia de usuario y la estética final del juego, sirviendo como un documento visual definitivo para la futura etapa de programación y desarrollo técnico.

Prototipo App Móvil: "Casita Deletreo"

Este trabajo se centra en el diseño de interfaz de usuario (UI) para una aplicación móvil educativa e interactiva orientada al público infantil, diseñada para facilitar el aprendizaje de la ortografía mediante mecánicas gamificadas en entornos naturales.

Se requería crear una experiencia móvil altamente visual y amigable que mantuviera la atención de los niños. Fue indispensable incluir un sistema de progresión de niveles, mecánicas de recompensas con monedas virtuales y opciones de personalización (tienda).

La solución se diseñó en torno a un flujo de navegación intuitivo basado en botones grandes, iconografía clara y colores vibrantes. Se definió la pantalla principal ("Mi Casita") integrando personajes guía, como un búho, para hacer la navegación más interactiva y menos confusa para usuarios de temprana edad.

El prototipo fue implementado visualmente estructurando los *wireframes* y maquetas finales en Canva. Se dimensionaron los elementos para pantallas móviles y se definieron las áreas táctiles de botones como "¡Jugar!" y "Tienda", asegurando proporciones ergonómicas.

Al finalizar, se entregó un diseño de interfaz pulido y funcional a nivel visual que demuestra claramente cómo los niños interactuarán con la aplicación educativa, facilitando la transición del concepto gráfico hacia el desarrollo de frontend móvil.
